■ 今日判断 · 编辑立场
过去两年 AI 的账单上只有 GPU 一栏，今天市场开始往里补第二栏。Agent 真正跑起来之后，除了模型推理，还要有人去跑浏览器、调工具、处理文件、调度任务、挂虚拟机，这些活落在 CPU 上。数据中心 CPU 业务单季收入同比增 59% 已经是发生过的事，不是推演。第三方机构说的 1:1 到 1:2 是数量比，金额上 GPU 对 CPU 仍有六倍以上的差距，别把"配比接近 1"读成"钱要追上"。

先看已经发生的那部分。该海外 CPU 厂商二季度营收 161 亿美元、同比增 25%，其中数据中心与 AI 业务收入 63 亿美元、同比增 59%、环比增 24%，该业务经营利润 25 亿美元、占其收入的 40%。公司在业绩电话会上的原话是服务器 CPU 需求持续远超可得供给，并据此上调了未来两年的资本开支计划。这是财报口径的数字，不是前瞻测算。

配比要分清数量和金额，两个口径差了六倍。第三方研究机构给出的判断是，Agent 时代 CPU 与 GPU 的配比从 1:4 到 1:8 转向 1:1 到 1:2；另有芯片厂商在公开场合给过方向一致的口径，称 AI 推理正把配比从 1:8 推向 1:1。这些说的都是数量比。按金额算是另一回事：独立测算显示 GPU 与其他加速芯片对 CPU 的金额比 2025 年约 7.9 倍、2026 年约 6.8 倍，此后稳定在 6.4 倍左右。数量配到 1:1，不等于 CPU 的采购金额要追上 GPU。

市场空间那个数要按原口径读。另一家海外 CPU 厂商在其 7 月的 AI 大会上把服务器 CPU 市场规模口径提到 2030 年 2200 亿美元，年初的口径是 1200 亿美元。这个口径有三处限定：说的是服务器 CPU 而非全部 CPU，2200 亿是 2030 年的终值而非三四年后的规模，测算方是厂商本身。

为什么 Agent 会把负载推回 CPU。过去 AI 资本开支的核心矛盾集中在 GPU，因为主要工作是模型训练与推理。Agent 大规模运行之后，一次任务里真正耗时的往往不是模型本身：打开网页、调用外部工具、读写文件、安排多步任务的先后顺序、并发跑多个 Agent，这些都要有进程在跑，而虚拟机与容器更多依赖 CPU 挂载。所以 AI 服务器里 CPU 的需求增速可能与传统服务器周期脱钩。

A 股这条线的映射落在国产 CPU 的渗透率上。性能这一档已经不是主要矛盾：国产 64 核产品的整数运算基准测试成绩为 933 分（双路口径），与海外同代产品的 878 分处在同一量级。约束在客户结构。2025 年国产 CPU 在互联网客户中的渗透率仍是个位数，卖方给的 2026 年预期是互联网采购的国产渗透率有望达到 10% 以上，客户构成从以信创为主转向信创与互联网并行。

覆铜板改按配额制供货，二三线 PCB 订单能见度拉到 3 至 4 个月
招商电子 鄢凡/程鑫/涂锟山 · PCB 产业链周度 · 0920 ／ 二三线 PCB 环节周期与投资阶段跟踪 · 0921 ／ 产业链调研交叉核对

覆铜板供应现按配额制进行，这在该环节的历史上没有出现过。传导下来是三段变化。高端 PCB 厂不稀罕做中端订单，把中端需求挤了出去；中低端厂拿不到覆铜板供给，接了也做不了；长尾需求因此流入腰部 PCB 厂。二三线厂的产能被挤兑，反映在订单能见度 3 至 4 个月。

定价基准同步换了。板厂改以出货时点的覆铜板价格作为定价基准，再向上适度加价索取利润空间。行业下行期市场份额是命脉，保供的价值高于比价，客户对价格的接受度因此超出预期。三季度多数中小 PCB 厂净利率已修复至 10% 以上的历史高点，按当前排产，四季度仍有进一步上升空间。

涨价节奏上，覆铜板逐月调价的保守预期持续到 2027 年 6 月后高位横盘，乐观预期到 2027 年底。本轮与历史周期的区别在于驱动来自供给而非需求：AI 需求占用了大量玻纤布产能，铜箔向高频低轮廓规格升级又持续推高加工费。

共封装降规的传闻更多影响情绪。训练场景是新增市场，交换机 PCB 的价值量更多转移到了载板上，传统高速交换机的升级和需求仍在快速增长。

GLOSSARY 新词速查
配额制供货
上游材料紧缺到无法满足全部订单时，供应商按客户的历史份额或战略级别分配可购数量，而不是价高者得。本轮覆铜板即按此供货，这在该环节的历史上没有出现过。
用途＝判断紧缺进到了哪一档。发涨价函说明还在用价格调节，改配额说明价格已经调不动量了。边界＝配额按客户分，不按订单分，所以它挤出的是中端与长尾需求，而不是均匀减量；受益方是能拿到配额的板厂，不是全行业。
CPU 与 GPU 配比
一台 AI 服务器或一个算力集群里 CPU 与 GPU 的数量之比。传统训练场景约 1:4 到 1:8，第三方机构预计 Agent 时代转向 1:1 到 1:2。
用途＝把"Agent 带动 CPU"这句话换算成可核对的机架配置数量。边界＝这是数量比，不是金额比。按金额算，GPU 与其他加速芯片对 CPU 仍有 6.4 倍左右的差距，配比走到 1:1 也不意味着采购金额接近。两个口径混读会把弹性放大数倍。
热沉片
直接贴在芯片裸片一侧、把热量从硅内部导出的高导热片层。金刚石方案是在 700 微米厚的硅上挖出 300 微米，再与金刚石键合，整体厚度不变。
用途＝区分金刚石在散热里的三个位置：热沉片在封装内、导热垫片在封装外、金刚石铜在液冷板。三者的落地顺序与确定性完全不同。边界＝热沉片的对手是硅本身的导热能力；液冷板那一层还可以靠提高冷却液流速来解决，所以金刚石铜的必要性弱于热沉片。
确收周期
设备从交付到客户验收、厂商确认收入之间的时间差。半导体设备的确收周期普遍在 12 个月左右，签单、发货、确收因此分属三个不同的时点。
用途＝把"新增订单 8 台"折算成当期能进报表的量。确收周期 12 个月意味着今年的订单大部分要到明年才体现在收入里。边界＝订单和确收不同步，用订单看景气、用确收看业绩，把两者混在一张表上会得出错误的增速。
