GLOSSARY 新词速查
UALoE / ESUN（Scale-up互联的以太网路线）
UALoE = UALink over Ethernet，把UALink的Scale-up语义跑在以太网物理层上；ESUN = Ethernet for Scale-Up Networking，是同一方向的以太网标准化努力。两者都在解决"如何用通用以太网生态组Scale-up域"，与英伟达NVLink的私有总线路线相对。
为何今日重要：AMD Helios用72颗MI455X组Scale-up域、机柜聚合带宽260TB/s，走的正是Pensando网络+UALoE Fabric；这条路线一旦成势，交换芯片与高速铜/光互联的可寻址市场会显著扩大。
Smart Retimer / OCP标准封装（Smart Swap）
Retimer完整恢复并重发时钟与信号，Redriver只做模拟均衡放大，二者封装脚位历来不通用。OCP Signal Conditioner标准封装把二者做成同一尺寸，于是同一块PCB可以按链路预算自由互换器件，无需重做加速卡或交换板。
为何今日重要：Astera Labs发布首批符合该标准的16-lane/200G每lane、3.2T产品并开始送样。互换能力降低了板卡设计的返工成本，是高速互联从"选型"转向"平台化"的信号。
球形硅微粉 M7 / M8 / M9 / M10 分级
按覆铜板的介电损耗等级划分的填料档次，等级越高对应更低损耗、更高频的应用（M8以上对应AI服务器高多层板与先进封装）。等级提升同时要求更细粒径、更严的金属杂质控制（需到几个PPB）与表面修饰能力。
为何今日重要：1.6T光模块PCB全层mSAP化与24-40层AI服务器板普及，把需求直接推到M8以上；而M8以上目前仍以日系供给为主，是"扩产也追不上"的典型卡口。
BCD工艺
在同一颗芯片上同时集成双极（Bipolar）、CMOS与DMOS三类器件的成熟制程特色工艺，兼顾模拟精度、数字逻辑与高压大电流驱动，是电源管理IC与DrMOS的主流平台。属特色工艺而非先进制程，产能扩张依赖代工厂的特色工艺资本开支。
为何今日重要：台积电全年Capex只有约10%分给特色工艺，而AI服务器一次/二次电源与DrMOS需求同步上量，BCD成为本轮成熟制程里缺口最显著的那一格。
